## 🧠 About Me

Hey, I'm a final-year **B.E. student in Artificial Intelligence and Machine Learning**, based in Bengaluru, India. 👋

I'm fascinated by a simple question: **How can we make machines understand language and turn information into something genuinely useful?**

That curiosity draws me toward **Natural Language Processing (NLP), Generative AI, and Intelligent Information Retrieval**. I enjoy exploring how machines process text, discover patterns, retrieve relevant knowledge, and generate meaningful responses.

My GitHub is a collection of projects from my learning journey—from chatbots and text analysis to topic modelling and retrieval-based applications. Each project gives me a chance to experiment with ideas, connect concepts with code, and learn what happens beyond the theory.

## 🔎 What I'm Curious About

- 🧩 **Language and Meaning:** Exploring how machines process words, context, ambiguity, and human language.
- 🧠 **Generative AI:** Learning how language models can produce useful responses and support real-world applications.
- 🔗 **Retrieval-Augmented Generation:** Exploring how relevant information can help make AI-generated responses more grounded in available knowledge.
- 🌏 **Accessible AI:** Interested in how language technologies can become more useful across languages and different user contexts.

## 🛠️ How I Learn

I believe curiosity starts the journey, but experimentation makes the learning stick. I enjoy breaking concepts into smaller pieces, trying different approaches, and learning from what works—and what doesn't.

I'm continuously strengthening my programming fundamentals and exploring the ideas behind the technologies I use. For me, every project is less about having all the answers and more about asking better questions.

## 🎯 Where I'm Headed

My goal is to grow into an **NLP / Generative AI Engineer**, developing a strong foundation in language technologies and learning to build intelligent applications that are useful, thoughtful, and accessible.

**One idea at a time. One experiment at a time. Always curious.** ✨
