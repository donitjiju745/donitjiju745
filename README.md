## 🧠 About Me

> I'm a final-year **B.E. student specializing in AI & Machine Learning** in Bengaluru, India — a builder who works across the full stack of modern AI: from **Deep Learning, NLP, and Computer Vision** research down to shipping production-ready **full-stack applications** with Java backends and React frontends.
>
> My north star is **making AI genuinely accessible in Indian languages** — right now that means designing multilingual, low-resource NLP systems (starting with Kannada) that don't treat English as the default. I learn best by building things from scratch rather than just following tutorials.

**🔭 Currently:**
- 🏛️ Building **NyayaMitra** — a bilingual Kannada legal AI assistant
- 🧠 Deep-diving into **LLM internals**, transformer architectures
- 🌐 Sharpening full-stack skills across **FastAPI / Java backends + React frontends**

**⚡ Fun fact:** I'd rather implement an algorithm from scratch and break it twice than copy-paste a working solution once.
